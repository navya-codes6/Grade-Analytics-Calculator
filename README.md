# Grade-Analytics-Calculator
A web-based grade calculator built with HTML, CSS, and JavaScript that calculates student averages, letter grades, and academic performance statistics.

Grade Analytics Calculator is a beginner-friendly web application that helps students calculate their academic performance. Users can enter course marks, calculate their average, determine their letter grade, and view a personalized student report.

This project was originally developed as a Python console application and later converted into a web application using HTML, CSS, and JavaScript to learn front-end web development concepts.

## Features

* Enter student name and course marks
* Calculate total marks and average
* Determine letter grades automatically
* Input validation for marks between 0 and 100
* Display a student performance report
* Responsive web interface

## Technologies Used

* HTML
* CSS
* JavaScript
